# winterfestivalmc-website
## If you want to update this website, please use Visual Studio Code and press "clone git repository", press this repository, and then inside the project, you will need to type "npm install"(need to download https://nodejs.org/en first) in your terminal, and then type "npm run dev" if you want to see the previews.

## 如果你想要更新此網站，請用Visual Studio Code，按下“Clone git repository", 並且選擇該repository, 在專案中，請先下載https://nodejs.org/en，並且在終端中打入"Npm install" ， 倘若想要預覽網站進度，請在終端輸入"npm run dev"

## caution ! you will need to be part of the Winter Festival MC team and be invited into this repository to edit the website
## 注意！必須是冬境之約 團隊的一員 以及被邀請進這個repository 才能編輯此網站
