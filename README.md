# winterfestivalmc-website
### If you want to update this website, please use Visual Studio Code and press "Clone git repository", select this repository, and then inside the project, you will need to type "npm install"(need to download https://nodejs.org/en first) in your terminal, and then type "npm run dev" if you want to see the previews. If you want to upload/update new stuff into GitHub, please press "Source Control" normally on the left side, the third icon, and press commit again. If you want to sync the project to your computer, you will need to type "git pull" in your terminal.

### 如果你想要更新此網站，請用Visual Studio Code，按下“Clone git repository", 並且選擇該repository, 在專案中，請先下載https://nodejs.org/en，並且在終端中打入"Npm install" ， 倘若想要預覽網站進度，請在終端輸入"npm run dev，如果要更新/上傳 東西，請按"Source Control"，通常在左側第三格，如果沒有請洽詢鴨子，如果需要同步更新內容到電腦，請在終端裡打"git pull" 終端開啟方式因系統而已，倘若是電腦直接開啟終端，請先用"cd winterfestivalmc-website" 在打入其他東西，若有問題一樣大叫鴨子，鴨子聽不到，請洽詢鴨子。

### caution ! you will need to be part of the Winter Festival MC team and be invited into this repository to edit the website
### 注意！必須是冬境之約 團隊的一員 以及被邀請進這個repository 才能編輯此網站
